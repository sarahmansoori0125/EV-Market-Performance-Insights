# Electric Vehicle Market Performance & Insights

## 1. Project Overview

This project analyzes electric vehicle (EV) specifications to explore differences across manufacturers, vehicle types, battery capacity, model years, and motor power. An interactive dashboard developed using Tableau Public presents these comparisons through data visualizations.

## 2. Project Objectives

- Analyze electric vehicle models across manufacturers.
- Compare average battery capacity across vehicle types.
- Examine the distribution of EV models by year.
- Compare average motor power across manufacturers.
- Present EV specifications through clear visualizations.

## 3. Dataset Description

- **Dataset:** OpenEV Data
- **Format:** CSV
- **Source:** [OpenEV Data GitHub Releases](https://github.com/open-ev-data/open-ev-data/releases)

The dataset contains electric vehicle specifications, including manufacturer, model name, vehicle type, year, battery capacity, and motor power.

## 4. Tools and Technologies

- **Tableau Public:** Dashboard creation and data visualization.
- **GitHub:** Project hosting and documentation.
- **CSV:** Dataset storage and input format.

## 5. Dashboard Visualizations

1. **EV Models by Manufacturer:** Compares the number of models across manufacturers.
2. **Average Battery Capacity by Vehicle Type:** Compares average net battery capacity across vehicle types.
3. **EV Models by Year:** Shows the distribution of model records across years.
4. **Average Motor Power by Manufacturer:** Compares average motor power across manufacturers.

## 6. Key Insights

The dashboard allows users to compare vehicle specifications, explore differences in battery capacity and motor power, and examine the distribution of EV model records across years. Specific findings can be added based on the observed chart results.
